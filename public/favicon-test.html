🛠️ If Favicon Not Showing:

  1. Hard refresh: Press Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)
  2. Clear browser cache: Open DevTools (F12) → Right-click refresh button → "Empty Cache and Hard Reload"
  3. Try incognito/private mode: Open a new incognito window and visit http://localhost:3000
  4. Check browser console: Press F12 → Console tab → Look for any favicon errors

  <link rel="icon" href="/favicon.svg" type="image/svg+xml" />
  <link rel="apple-touch-icon" href="/favicon.ico" />
  <link rel="manifest" href="/manifest.json" />
  <meta name="theme-color" content="#dc2626" />
  <meta name="msapplication-TileColor" content="#dc2626" />
</Head>
